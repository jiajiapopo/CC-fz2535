I used to think code was the instructions that told computers what to do. I realized that maybe I have been writing and reading a kind of code for many years. Music notation is a code by Kittler's definition: "namely one-to-one, finite sequences of symbols, kept as short as possible but gifted, thanks to a grammar, with the incredible ability to infinitely reproduce themselves," but it doesn't keep it as short as possible.
In Form+Code, code is defined primarily as computer programs, but they extend the definition to include instructions beyond computer code. It's just a precise way of explaining how to do something. Graphic scores go further. Treatise is a graphic score composed by the British composer Cornelius Cardew. It is full of lines and shapes with no explanation and no limit. The repetition of a character reminds the performer that there is a structure. But every version is unique. You can't follow any keys. You can only decide what it means and play that. It all depends on how the performer plays it. I once wrote a graphic score piece, and I listened to different performers playing it. It's very interesting because you get surprised by how they understand your music.
